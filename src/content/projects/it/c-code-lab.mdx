## Esercitarsi nel browser

CP Lab raccoglie 51 esercizi di Complementi di Programmazione DIAG del periodo 2024–2026. Ogni esercizio unisce la traccia a un editor C e al feedback di esecuzione.

## Eseguire C localmente

Il runner usa picoc-js nel browser. File di supporto, soluzione e tester vengono combinati prima dell'esecuzione. Gli include locali e alcuni costrutti del preprocessore vengono normalizzati per l'interprete.

Il codice viene salvato per esercizio in localStorage, con salvataggio automatico e manuale. L'esecuzione avviene sul dispositivo dell'utente, senza una coda server.

## Limiti

L'interprete supporta un sottoinsieme del C. I tester sono generati manualmente o tramite script e non sono test ufficiali DIAG. Gli esercizi senza tester vengono segnalati esplicitamente.
